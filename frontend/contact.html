Are you available for full-time employment?
+
Yes — I'm actively looking for full-time SDE roles in Delhi NCR or Remote. I'm targeting Full-Stack / Backend Developer positions at product companies. If you're hiring, I'd love to talk.
How long does a typical project take?
+
A simple REST API backend: 1–2 weeks. A full-stack web app with auth, admin, and deployment: 3–6 weeks. A production-grade platform like a dealership system: 2–3 months. I give accurate estimates after understanding your requirements.
What does your development process look like?
+
Discovery call → requirements doc → milestone-based delivery → review cycles → production deployment → handover. I use GitHub for version control, write tests, document APIs, and deploy with CI/CD. No surprises, no scope creep without discussion.
Can you integrate AI features into an existing product?
+
Yes. I specialize in adding RAG-based NLP features using pgvector + OpenAI API, specifically within Django applications. If you have a database-backed Django app and want to add smart search, a Q&A assistant, or semantic recommendations — that's exactly what I'm building right now.
